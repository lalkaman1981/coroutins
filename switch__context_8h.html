Detailed Description

Core data structures for coroutine context switching.

Defines execution context structure for saving and restoring coroutine CPU state during context switches.

Switch execution between two coroutine contexts.

Parameters
old_contextContext to save current CPU state into
new_contextContext to restore and resume execution from

Performs complete context switch by saving all registers and extended CPU state to old_context, then restoring from new_context. Implemented in assembly for both Windows and Linux calling conventions.
